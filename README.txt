ALASG v0.8 - GitHub Pages

1. Crie um repositorio publico no GitHub.
2. Envie TODOS os arquivos desta pasta para a raiz do repositorio (index.html, game.js, style.css, sede_1.png, etc).
3. Em Settings > Pages, selecione Deploy from a branch, main, /(root) e Save.
4. Abra a URL do GitHub Pages no Chrome Android. Menu de tres pontos > Adicionar a tela inicial.

O chat atual e programado, nao e IA generativa. A operacao e simulada no navegador e avanca ao reabrir (ate 7 dias). Os dados financeiros e quilometragens iniciais sao simulados.

Para preservar a partida antiga, exporte o backup JSON na versao anterior e importe em Configuracoes na nova versao.
